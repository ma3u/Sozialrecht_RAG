## Report Types

### Deployment Reports
Generated after each major deployment with:
- Import statistics (norms, amendments, relationships)
- Performance metrics (duration, throughput)
- Per-volume breakdown
- Success/failure status
- Data quality metrics

### Analysis Reports
Generated during analysis phases:
- Data quality assessments
- Coverage statistics
- Improvement recommendations
- Findings and observations

## Naming Convention

- **Deployment Reports**: `DEPLOYMENT_REPORT_YYYYMMDD_HHMMSS.md`
- **Analysis Reports**: `[TOPIC]_ANALYSIS_SUMMARY.md`
